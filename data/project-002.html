项目概述

rocom-helper 是一个面向《洛克王国》的自动化辅助工具，使用 Python + tkinter 构建图形界面，通过 DD 内核级虚拟驱动在底层模拟鼠标键盘输入，绕过用户态 API hook，实现对游戏的安全自动化操作。

项目核心挑战在于 反作弊（ACE/TenProtect） 环境下的隐蔽性——全程不使用 EnumWindows、FindWindow、SendInput、mouse_event 等可被监控的用户态 API，所有输入走内核 HID 设备路径，所有画面读取走 GDI BitBlt 纯读操作。

核心功能

自动点击：基于三次贝塞尔曲线的鼠标轨迹生成，配合正弦波调速模拟人类先加速后减速的物理惯性，并在移动路径中注入 10~20ms 间隔的随机微抖动。点击间隔、按下持续、偏移范围、曲线幅度全部支持范围随机取值，避免规律性特征。

牵手模式（战斗辅助）：使用 opencv-python 的 cv2.matchTemplate(TM_CCOEFF_NORMED) 进行模板匹配，Canny 边缘检测预处理后判定战斗 UI 状态。检测到进战后通过 DD 驱动自动按下技能键（默认 x），并引入 energy.png 按键钩子机制——energy 图标不可见时跳过按键，防止脱战后误触发。

一键更新：C# Windows Forms 编写的独立更新器（编译后仅 ~18KB），带可视化下载进度条和百分比显示。使用安全单线程下载（避免 Cloudflare R2 Range 请求损坏），支持自我替换。

全局热键：通过 GetAsyncKeyState 轮询实现 Ctrl+Shift+S/P/X 快捷键，窗口最小化/失焦时仍正常响应。

技术栈

前端 GUI：Python tkinter + ttk，主题支持切换，反检测参数独立成行布局。
内核驱动：DD64.dll（C++ 内核驱动），通过 DD_btn/DD_mov/DD_key 完成输入，DD_todc 转换 Windows VK 键码到 DD 专属键码。
图像识别：opencv-python-headless + numpy，GDI BitBlt 屏幕捕获 + Canny 边缘检测 + 归一化互相关模板匹配。
打包部署：PyInstaller 双 exe 策略（主程序 onedir + 更新器 onefile）+ csc.exe 编译 C#。
配置持久化：`default.json` + `custom.json` 双文件方案，主题 JSON 文件可扩展。

安全设计

所有 API 调用经过 ACE 审计分级：P0（高危）如 EnumWindows、SendInput 完全清除；P1（中危）如 FindWindow 以纯读方式受限调用；P2（低危）如 GetDC(0)、GetAsyncKeyState 作为启动时一次性调用留存。输入路径全程走 DD 内核驱动，无用户态 API 暴露。
