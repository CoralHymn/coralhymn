项目概述

CosBox 是一个面向 AI 角色扮演的状态驱动叙事客户端。核心不是聊天软件，而是结构化角色状态：穿着、衣柜、当前地点、地点库、日程与属性都是数据，不是消息附件。LLM 通过 Context Pipeline 精确感知当前状态、世界信息与压缩后的对话。

核心功能

  • 角色状态编辑器与实时预览，状态变更自动生成快照
  • 类 Git 增量快照版本图，支持任意点回溯与分支
  • 地点库与衣柜分类管理，换装槽位只匹配类型正确的衣物
  • World Info 触发、状态摘要与历史压缩组成的 Context Pipeline
  • 兼容 OpenAI、Claude、Gemini、DeepSeek、Ollama 等二十余种 LLM 端点
  • SillyTavern V3 角色卡导入导出

工程亮点

TypeScript strict 模式与零 any 约束，核心层使用纯函数维护状态模型和快照版本图；Svelte 5 Runes 提供响应式状态；Dexie.js 将快照、World Info 与配置持久化到 IndexedDB。项目同时配备 Vitest 单元测试与 Playwright 端到端测试，并已接入 Tauri 2 桌面与 Android 打包骨架。
