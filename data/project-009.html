项目概述

RWMP2_Decryptor 是《铁锈战争》模组加密工具 RWMP2 的解锁工具，使用 Python 编写，提供 GUI、WebUI 与纯 HTML 三种使用方式。HTML 版本基于 Pyodide，完全在浏览器中运行，适合移动设备与免安装场景。

核心功能

  • RWMP2 加密模组文件解密
  • GUI 与 WebUI 双界面
  • 纯 HTML 在线版本，无需安装
  • 支持服务器部署与批量处理
