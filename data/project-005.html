项目概述

Clash-Gate 是一个基于 Python + ttk/ttkthemes 的 Clash Verge 节点端口分配器。它读取 Clash Verge 本地订阅文件，把不同订阅里的节点或策略组分配到本机不同端口，并利用 Mihomo 内核的 listeners 功能让每个端口固定使用指定节点出口。

核心功能

  • 自动发现 Clash Verge Rev 数据目录并解析 profiles.yaml
  • 多个订阅同时加载，左侧树按订阅分组显示
  • 节点/策略组分配到任意端口，支持 HTTP + SOCKS5 mixed 入站
  • 每个订阅启动独立 Mihomo 引擎，不干扰正在运行的 Clash Verge
  • 端口测速，显示延迟与下载速度
  • 轮询外部控制器，记录访问日志与上下行流量

技术实现

项目拆分为配置生成、引擎管理、GUI、端口测速、流量日志和订阅解析模块。每个订阅文件会被复制为独立运行配置，写入 mixed 类型 listeners，再以独立 Mihomo 进程启动。访问日志通过每个引擎的 /connections 接口定时获取。
