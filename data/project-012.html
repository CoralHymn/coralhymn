wplace Discord Bot

类型
Discord 机器人
技术栈
Python + Selenium + discord.py
平台
Windows / Linux

项目概述

wplace Discord Bot 是一个实时监控 Wplace 像素画变化并通过 Discord 发送通知的机器人，同时支持从 wplace.eralyon.net 回溯任意历史日期的像素画截图。项目支持多区域监控、独立 Webhook 与完整的权限体系。

核心功能

  • Selenium 实时监控指定区域，自动截图比对
  • 像素级差异对比并生成高亮对比图
  • 历史日期像素画截图
  • Discord 机器人或 Webhook 通知
  • 21 个命令：监控管理、截图、历史、权限、状态查询
  • 白名单与超级管理员权限控制
